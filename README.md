# Daan Taheij — Portfolio

Personal portfolio site for Daan Taheij, graphic & creative designer. High-end, editorial, typography-driven design system built as a foundation for the full portfolio.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Motion (Framer Motion) for view-triggered reveals and hover interactions
- GSAP + ScrollTrigger for the hero intro timeline and scroll-scrubbed parallax
- Lenis for smooth scrolling

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Status

Only the homepage is built so far: Hero, Selected Work (with placeholder visuals), About preview, and Contact. Work/About/Contact detail pages are not built yet — this is the first iteration of the design system and homepage.
